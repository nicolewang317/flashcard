# Transport class overview — integration

The supplied class notes and classification-chart screenshot were checked against the existing 28-card transport set. The set now contains 36 cards: 8 new learning objectives, 7 new scored questions, and one self-assessed drawing card. Existing IDs and review histories are preserved.

New objectives: net-flux calculation; uniporter recognition; energy release versus energy capture; electrochemical gradient versus action potential; drawing symport/antiport; recognizing cardiac Na/Ca antiport; simple O₂ diffusion in red blood cells; GLUT1-mediated glucose diffusion in red blood cells.

Existing simple/facilitated diffusion, glucose permeability, channels/carriers, active/passive, Na/K stoichiometry, primary/secondary energy, electrochemical forces, GLUT/SGLT comparison and pump-dependence cards cover the repeated notes. The symport card now uses an intestinal-uptake diagram. Pump energy and carrier explanations were tightened, and inaccurate old concept labels corrected. See TRANSPORT_CLASS_CHANGES.json for IDs and prior wording.

Draw the two carrier patterns on paper before flipping; the answer diagram appears only on the back. Identification cards show the arrows without naming the pattern. The diagrams also appear in Diagram lab. Text exports describe the arrows in words so that they remain usable without graphics.

The supplied chart is a course-level grouping. Uniport/symport/antiport describe transported species and directions; the energy mechanism must be determined separately. An electrochemical gradient is not an action potential. Downhill transport can release free energy, but useful work needs coupling and does not automatically produce ATP. Ion movement must be assessed against the combined concentration and voltage effects.

Human examples are illustrative, not exclusive to a single cell type: red blood cells use O₂ simple diffusion and GLUT1 facilitated diffusion; neurons have passive ion channels and ATP-driven Na/K pumps; intestinal epithelial cells have Na/glucose symport; heart muscle cells can use Na/Ca antiport for Ca extrusion.
